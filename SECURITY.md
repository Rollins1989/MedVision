# Security Policy

## Scope

MedVision is a research/educational prototype. It is not designed or approved for clinical deployment.

Please do not include patient-identifying information, medical images containing private information, credentials, API keys, or other secrets in issues or pull requests.

## Reporting a vulnerability

If you discover a security issue in the software, please avoid publishing exploit details in a public issue. Contact the repository maintainer privately through the contact information associated with the GitHub account.

For issues involving exposed credentials or sensitive data, include enough information to reproduce the problem without disclosing the secret itself.

## Model and clinical safety

Model predictions, confidence scores, and Grad-CAM visualizations are research outputs. They must not be used as a substitute for qualified clinical judgment or for diagnosis, treatment, triage, or patient-management decisions.
